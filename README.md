# ERC20 Token Template

A customizable ERC20 token contract built with OpenZeppelin.

## Features
- Custom name, symbol, initial supply and max supply
- Owner can mint up to max supply
- Anyone can burn their own tokens

## Deployed Contract
Sepolia Testnet: 0x847C290d0016DcaEdAf75b3F462FE251D8CdDC2b

## Constructor Parameters
- name: token name
- symbol: token ticker
- initialSupply: tokens minted at deployment
- maxSupply: hard cap on total supply
